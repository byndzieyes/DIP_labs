# Цифрова обробка інформації

Репозиторій містить лабораторні роботи з дисципліни «Цифрова обробка інформації» (ЦОІ / DIP).

## Лабораторні роботи

| Робота                   | Тема                                        | Матеріали                                          |
|--------------------------|---------------------------------------------|----------------------------------------------------|
| [Лабораторна №1](lab01/) | Детерміновані сигнали для обробки інформації | Програма та графіки                                |
| [Лабораторна №2](lab02/) | Основні операції над сигналами              | Програма та графіки                                |
| [Лабораторна №3](lab03/) | Кореляція та автокореляція сигналів         | Програма та графіки                                |
| [Лабораторна №4](lab04/) | Синтез вербальної інформації                | Програма та аудіофайли                             |
| [Лабораторна №5](lab05/) | Маркування інформації                       | Видимий знак, прихований LSB та зчитування         |
| [Лабораторна №6](lab06/) | Кількісна оцінка інформації                 | Програма, таблиці та графіки                       |
| [Лабораторна №7](lab07/) | Дискретне перетворення Фур’є, варіант 5     | Власне ДПФ, графіки та результати                  |
| [Лабораторна №8](lab08/) | Швидке дискретне перетворення Фур’є         | Власне ШПФ, порівняння з ДПФ, графіки та результати |
| [Лабораторна №9](lab09/) | Дискретна згортка сигналів                  | Програма з власною реалізацією згортки             |


Кожна лабораторна робота знаходиться в окремій папці. Звіти, навчальні методички та інші допоміжні матеріали зберігаються поза цим репозиторієм.

## Встановлення залежностей

```powershell
py -m pip install -r requirements.txt
```
