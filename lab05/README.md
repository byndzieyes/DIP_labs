# Лабораторна робота №5 — Маркування інформації

Одна програма `main.py` з графічним інтерфейсом: видимий водяний знак,
приховане маркування методом LSB і витягування прихованого маркера.

## Запуск

З папки `DIP_labs`:

```powershell
py -m pip install -r requirements.txt
py lab05/main.py
```

Потрібні Python 3.10 або новіший, NumPy, Pillow та tkinter (входить до
стандартного встановлення Python для Windows).

## Видимий знак

1. Натисніть **Відкрити зображення** і виберіть фотографію.
2. Натисніть **Відкрити маркер** і виберіть логотип або напис.
3. Встановіть непрозорість повзунком: 0 — невидимий, 1 — повністю непрозорий.
4. Натисніть **Нанести видимий**, потім **Зберегти результат**.

Логотип пропорційно зменшується до третини ширини та висоти картинки,
якщо потрібно, й розміщується праворуч унизу. Прозорий фон PNG-маркера
враховується. Непрозорий фон JPG теж буде видно як частину логотипа.
Змішування кольорів: `результат = (1 − α) × фон + α × маркер`, де α
враховує повзунок і власну прозорість маркера.

## Прихований знак і його зчитування

1. Відкрийте основне зображення та маркер.
2. Натисніть **Нанести прихований** й збережіть `hidden_watermark.png`.
3. Через **Відкрити зображення** відкрийте саме цей збережений файл.
4. Натисніть **Зчитати прихований** і збережіть `extracted_marker.png`.

Маркер перетворюється на сіре зображення розміром із контейнер; якщо
пропорції різні, він розтягується. Прозорі ділянки отримують білий фон.
Яскравість маркера квантується до чотирьох рівнів: діапазони 0–63, 64–127,
128–191, 192–255 кодуються числами 0, 1, 2, 3.

У кожному каналі R, G, B два молодші біти замінюються однаковим кодом маркера:
`новий_канал = (канал & 252) | код_маркера`. Колір кожного каналу змінюється
щонайбільше на 3 одиниці з 255. Оригінальна картинка в пам'яті не змінюється.
При витягуванні читаються два молодші біти, а рівні сірого відновлюються
як 0, 85, 170, 255. Точне відновлення всіх 256 відтінків не передбачене.

PNG зберігає біти без втрат. JPEG, масштабування та фільтри можуть зруйнувати
прихований знак.
